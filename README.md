# Liraasa 4.0: the published codex

Generated by `npm run publish:guide` in the Liraasa Workbench and committed here after every rebuild. Do not edit this branch by hand: its source is on `master` of https://github.com/nicolasbulgarides/Liraasa.

- **liraasa_lexicon.json**: the whole language in one JSON, lexicon and grammar, for reading and for language tools (the same file as liraasa_4_0_llm.json).
- **Liraasa_Reference_Grammar.pdf**: the Reference Grammar (also as HTML).
- **Liraasa_Invitation.pdf**: *Liraasa: An Invitation*, a short introduction.
- **Liraasa_4_0_Lessons.pdf**: *The Grammar in Lessons*, twenty short lessons to study the grammar a little each day (also as HTML).
- **liraasa_4_0_complete.json**: the complete lexicon, every form and every ruling.

The names without an edition number stay the same from edition to edition, so links to them keep working: https://github.com/nicolasbulgarides/Liraasa/blob/codex-latest/liraasa_lexicon.json
