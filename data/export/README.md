# Liraasa — Montreal Forced Aligner export

Generated by `npm run export:mfa`. Do not edit by hand; change the mapping in
`src/core/phonetics/g2p.ts` and regenerate.

## Files

| File                            | What it is                                                                                                                    |
| ------------------------------- | ----------------------------------------------------------------------------------------------------------------------------- |
| `liraasa_mfa_ipa.dict`          | **The dictionary.** IPA phones. This is the one to pass to MFA.                                                               |
| `liraasa_mfa_ascii.dict`        | The same, with ASCII phone labels, for tooling that dislikes non-ASCII.                                                       |
| `liraasa_mfa_ipa_stressed.dict` | IPA with a stress digit on each vowel (`i1`, `a0`). Only useful if your acoustic model was trained with stress-marked phones. |
| `liraasa_phones_ipa.txt`        | The 24-phone inventory, one per line. MFA wants this when training a new model.                                               |
| `liraasa_phones_ascii.txt`      | The same inventory in ASCII labels.                                                                                           |
| `liraasa_syllables.tsv`         | Syllabification and stress for every word. For you, not for MFA.                                                              |
| `mfa_export_report.json`        | Counts, the phone inventory, the proper names found, and the open questions.                                                  |

## Using it

```sh
# Validate the dictionary and your corpus first.
mfa validate /path/to/corpus data/export/liraasa_mfa_ipa.dict

# Train an acoustic model on your own recordings. Liraasa has no pretrained
# model, so this is the normal path.
mfa train /path/to/corpus data/export/liraasa_mfa_ipa.dict liraasa.zip

# Then align.
mfa align /path/to/corpus data/export/liraasa_mfa_ipa.dict liraasa.zip /path/to/output
```

Your corpus directory holds a `.wav` and a matching `.lab` or `.TextGrid` per
recording, with the transcript in Liraasa orthography. **Lowercase the
transcripts**, or pass `--clean`: the dictionary is keyed lowercase, including
proper names.

## Coverage

49,511 distinct orthographic words:

| Source                                                        | Words  |
| ------------------------------------------------------------- | ------ |
| Inflections (`-ti`, `-ri`, `-tiri` on every form)             | 29,778 |
| The seven forms of all 1418 headwords                         | 9,926  |
| `-yo` / `-vu` / `-pago` derivations, plus their plurals       | 8,506  |
| Numerals 0–999 and the scale words                            | 1,002  |
| Attested in the examples and corpus                           | 822    |
| Function words, pronouns, correlatives, time words, particles | 252    |
| Colour words                                                  | 45     |
| Proper names found in the texts                               | 14     |

The inflection and derivation rows are generated across the whole paradigm
rather than only where attested, because an aligner fails on any word missing
from the dictionary and a singer may legitimately use any of them.

Bound morphemes are **excluded**. `function_words` lists `-ti`, `-ri`, `-yo`,
`-vu`, `-pago` and `-na` as entries; those are suffixes, never standalone
tokens, so they are not dictionary words. `validate.py` filters them the same
way.

The 14 names are `aviya`, `dorin`, `dorinti`, `hypermatria`, `ilora`, `kipo`,
`lina`, `lunaria`, `melodia`, `merceria`, `nicolas`, `pietri`, `velina` and
`vorbalira`. Words from `HISTORICAL` examples are excluded — `daza`, `raetae`
and `azurae` are marked undefined by the 0.7 workbook itself and are not words
of the language.

## Pronunciation variants

A word with vowel hiatus gets a second entry: the careful pronunciation, where
every vowel is its own syllable, and a glided one. The guide permits this —
"hiatus vowels may glide without changing spelling" in rapid speech — and the
spelling never contracts, so both are correct.

```
dorvaasa	d o r v a a s a
dorvaasa	d o r v a s a
```

MFA will pick whichever fits the audio. If you want only the careful
pronunciation (likely for sung material, where the hiatus is the point), strip
the second line of each pair.

## The rules this encodes

From the Grammar Guide §5, "Sound and spelling":

- Five pure vowels, `a e i o u`, "roughly as in Spanish or Italian".
- Core consonants `l m n r s v y`; around them `b d p t g h z k c f j`.
- `sh` and `ch` occur only in a few colour and number words — `shada`, `ocha`.
- **Neighbouring vowels are separate syllables.** `soraasa` is so-ra-a-sa,
  `opioa` is o-pi-o-a.
- A medial cluster splits between its consonants: `bal-bu`, `mas-ka`, `lem-vo`.
- A grandfathered initial cluster stays together: `kro-no`, `tra-na`.
- Stress is penultimate: `LI-ra`, `lu-mi-A-sa`, `da-pa-DO-nu`.
- `g` is hard everywhere — the guide says `gura` "keeps its hard g".

Each of those is covered by a test in `src/core/phonetics/g2p.test.ts`, using
the guide's own examples as the expected values.

## Two open questions — your call

Both letters occur before several different vowels, so a phonetic spelling
cannot be giving them positional variants. I picked a documented default for
each; changing one is a one-line edit in `src/core/phonetics/g2p.ts` followed
by `npm run export:mfa`.

### `c` → currently `/k/`

Appears before all five vowels: `cuara`, `cemo`, `cilni`, `cono`, `cupa`.
Spanish would read `cuara` with /k/ but `cemo` with /s/ or /θ/, which would
make the spelling unphonetic. `/k/` matches the guide's explicit statement that
`g` is hard in every position.

**The cost:** `c` and `k` then spell one phoneme, so `cono` and a hypothetical
`kono` would be homophones. If you would rather `c` were `/s/` or `/t͡s/`, say
so — that is a pronunciation decision, not something the data settles.

### `j` → currently `/d͡ʒ/`

Appears before o, u and e: `juba`, `jomru`, `jemla`. `/d͡ʒ/` as in the English
"jewel" that `juba` (gem) echoes. The colour word `ojo` would suggest Spanish
`/x/` instead.

### A smaller one: `r`

Emitted as a single phone `r`. Whether it is a tap or a trill does not change
the dictionary, but it will change how you record and train. Worth deciding
before you cut the training set.
